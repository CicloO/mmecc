AdvancedMotionBlur  ver 0.3.0
作者：CicloO

────────────────────────────────
■ 简介
────────────────────────────────
MikuMikuEffect 用的动态模糊。
同时处理镜头运动和模型自身的动作：镜头转动、平移时整个画面按深度拖影；
角色挥手、甩头发时，手和发梢沿各自的运动方向拖影，固定镜头下也有效果。

・快速动作的拖尾会延伸到轮廓外，覆盖在背景上
・切镜时自动停用镜头拖影，角色自身的动作模糊保留
・可以用附带的控制器模型（PMX）按关键帧调强度、长度，或关闭镜头模糊
・拖影长度按 30 fps 的一帧计算，30／60 fps 导出的长度一致

────────────────────────────────
■ 动作环境
────────────────────────────────
・MikuMikuDance 9.32 x64
・MikuMikuEffect 0.37 x64
・DirectX 9.0c（June 2010）运行库
其他版本未确认。

────────────────────────────────
■ 使用方法
────────────────────────────────
1. 解压时保持 src 文件夹内的文件在一起，不要单独移动。
2. 把 src\AdvancedMotionBlur.x 当作附件载入。
   附件的绘制顺序放在场景、舞台等附件之后。
3. 附件的 Si 是强度。1 为标准，0 为关闭。可以注册关键帧。
4. 暂停时画面是清晰的（没有上一帧可比较）。请播放或导出确认效果。

※ 导出时从片段开始前多留 1 帧，第一帧也能得到模糊。
※ 不要和其他动态模糊 MME 同时使用。

────────────────────────────────
■ 控制器（AdvancedMotionBlurController.pmx）
────────────────────────────────
作为模型载入（不要改文件名），在表情面板调节，可注册关键帧。
权重全部为 0 时与没有载入控制器相同。

  眉  Strength +    强度最多加倍
      Strength -    强度降到 0
  眼  Shutter +     快门角调到 360°（拖影加倍）
      Shutter -     快门角调到 0°（无拖影）
  口  Streak +      拖影最大长度加倍
      Streak -      拖影最大长度降到 0
  他  Threshold     加大速度死区：慢的动作保持清晰，只糊快的动作
      Force Cut     0.5 以上时，该帧当作切镜处理（自动判定漏掉时用）
      Keep Camera   0.5 以上时，不做自动切镜判定（快摇被误判时用）
      Camera Off    0.5 以上时，关闭镜头运动的模糊，只保留角色自身动作的模糊

────────────────────────────────
■ 按对象选择模糊来源
────────────────────────────────
MMEffect → エフェクト割当（Effect Mapping）→ GeometryData 页，
按模型整行选择下列效果：

  MotionGeometry.fx   镜头运动 ＋ 模型动作（PMX／PMD 的默认）
  DepthVelocity.fx    只有镜头运动（附件、舞台的默认）
  ObjectMotion.fx     只有模型自身的动作

想让整个画面都不受镜头运动影响时，把 Settings.fxh 的
MB_CAMERA_MOTION 改为 0，或使用控制器的 Camera Off。

────────────────────────────────
■ 常用设置（src\Settings.fxh）
────────────────────────────────
修改后保存，在 MME 里重新载入附件即可生效。

  MB_SHUTTER_ANGLE     快门角，默认 180
  MB_MOTION_SCALE      强度倍率，默认 1.3
  MB_MAX_STREAK        拖影最大长度（1080p 下的像素），默认 64
  MB_SPEED_THRESHOLD   速度死区（像素），默认 3
  MB_SAMPLE_JITTER     1 = 细颗粒状拖影（默认），0 = 残影状拖影
  MB_QUALITY           0／1／2 = 低／中（默认）／高，3 = 固定 16 采样
  MB_CAMERA_MOTION     0 = 只模糊模型自身的动作
  MB_TRAIL_ALPHA       1 = 透明背景导出时拖尾带透明度
  MB_ACCESSORY_MOTION  1 = 移动的 .x 附件也有自身的拖影

其余参数见 docs\PARAMETERS.md。

────────────────────────────────
■ 已知问题
────────────────────────────────
・从 0.2.0 升级时，用旧控制器保存的工程在载入新控制器时，部分工程会让 MMD 崩溃
  （选择“pmm文件适配该模型并继续”时）。可在旧工程里先删除控制器模型并保存，
  再重新载入新控制器（控制器的表情关键帧需要重新注册）。
・描边类后处理效果如果在本效果之后绘制，描边不会被模糊。
・顶点数超过 262,144 的模型，模型动作模糊回退为镜头模糊
  （可把 MB_HISTORY_SIZE 改为 1024）。
