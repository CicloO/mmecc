# 更新日志

标签格式为 `AdvancedMotionBlur/v<版本>`。

## 未发布

- 采样抖动 `MB_SAMPLE_JITTER` 默认开启：拖影采样按像素错开，规则的残影条纹变成细颗粒。设为 0 回到残影状拖影。
- 切镜判定改为看屏幕位移：五点中值，镜头朝向不变时再用 7×5 个点补查位移和缩放，位移超过画面高度的 5%（`MB_CUT_SCREEN_HEIGHT`）且速度突增 3 倍以上即判为切镜。基线工程的 531、751、831 三处同角度切镜都能判对，环绕和快摇不误判。原有的朝向判据保留兜底。
- 切镜帧保留角色自身的动作模糊（`MB_KEEP_OBJECT_MOTION_ON_CUT`，默认开）：顶点历史改存世界坐标，切镜帧背景回到原色，角色仍有拖影。世界空间瞬移超过 `MB_TELEPORT_DISTANCE`（50）的顶点丢弃历史。
- 控制器其他栏新增 `Force Cut` 与 `Keep Camera`，可注册关键帧覆盖自动切镜判定。
- 预览允许 0.1–100.1 ms 的帧间隔，约 10 fps 的预览也有模糊；顶点历史按图集时间戳校验，去掉与 `ELAPSEDTIME` 的比较。重绘同一帧时保留相机速度，避免继续快摇时误判切镜。
- 拖影上限、速度死区和控制器量程按画面高度换算（`MB_SCALE_STREAK_WITH_HEIGHT`，默认开，以 1080p 为基准）。
- 可选开关（默认关）：`MB_TRAIL_ALPHA` 透明底拖尾（预乘 RGBA）、`MB_TRANSLUCENT_MOTION` 普通 Alpha 材质参与模糊、`MB_ACCESSORY_MOTION` 移动的 `.x` 附件用矩阵历史计算自身拖影。
- 修正模型漏记一帧后重新出现时的错误拖影；无有效历史或曝光为零时跳过分块速度搜索；分块归约改为横纵两步，并补回极小视口右侧和底部漏掉的速度。
- 载入更快：`AdvancedMotionBlur.fx` 在 MME 用的 `d3dx9_43` 下约 1.3 秒。

- 新增速度死区 `MB_SPEED_THRESHOLD`：拖影先减去该长度，慢的部分保持清晰，只模糊快速动作。控制器"其他"栏新增单个表情 `Threshold`（最多再加 16 px）。
- 默认效果加强：快门角保持 180°，`MB_MOTION_SCALE` 1.0 → 1.3，`MB_MAX_STREAK` 48 → 64 px，`MB_SPEED_THRESHOLD` 3 px。恢复 0.2.0 观感的设置写在参数手册。
- 运动轮廓内侧透出背景（`MB_EDGE_BACKGROUND`，默认开）：以前轮廓内侧完全不透明，只有外侧淡拖尾，观感是"模型内比模型外糊"；现在轮廓两侧连续虚化，细的部位变成半透明。设为 0 回到 0.2.0。
- 修正轮廓外拖尾把描边打碎成一列列点（`MB_TRAIL_SPREAD`，默认 0.35）：拖尾的方向容差随距离放宽，各部位运动方向略有差异时拖尾仍连续。设为 0 回到 0.2.0。
- 修正运动轮廓上残留的深色虚点（`MB_OUTLINE_FRINGE`）：MMD 抗锯齿把描边的深色渗到辅助缓冲记为背景的像素上，这些像素原地不动；现在它们跟着描边一起模糊。用户关闭 MMD 抗锯齿后虚点消失，确认了原因。轮廓上被记为半透明、紧贴描边的像素也一并处理（调试视图显示虚点大多落在这类像素上）。
- 描边像素借速度的范围从相邻 4 像素扩到 3 px 内 8 个方向（`MB_OUTLINE_SEARCH`）；轮廓内模糊的颜色改用线性过滤（`MB_LINEAR_COLOR`）。
- 载入加快：MME 编译 `AdvancedMotionBlur.fx` 从约 20 秒降到约 2 秒（分块归约改为固定循环上限，描边柔边修正只搜索一次）。
- `MB_QUALITY` 重新定义：`0`／`1`／`2` 按拖影长度分配采样数，间隔 4／2／1 px；默认 `1`。`3` 保持 0.2.0 的固定 16 采样（长拖影呈残影状）。原来的 8／24 采样档位取消。

## 0.2.0 · P1 控制器版

- 快速前景的拖尾可延伸到轮廓外（TileMax／NeighborMax），覆盖空白底色和较远的场景；`MB_EXTEND_FOREGROUND=0` 可回到 P0 的轮廓内模糊。
- 描边修正：MMD 原生描边和单像素后处理暗线从相邻表面借用速度，`MB_OUTLINE_MOTION` 控制。
- PMX／PMD 默认记录顶点历史，固定镜头下也有角色动作模糊（`MB_AUTO_MODEL_MOTION`）。
- 新增 PMX 实时控制器 `AdvancedMotionBlurController.pmx`：眉 `Strength ±`、眼 `Shutter ±`、口 `Streak ±`，可注册表情关键帧。
- 快门角固定按 30 fps 的一帧计算，30 和 60 fps 导出的拖影长度相同；删除 `MB_OUTPUT_FPS`。
- 修正载入后画面偏移（全屏四边形局部 UV 与半像素补偿）。
- 目录改为 `src/`、`docs/`、`fixtures/`、`tools/`；新增参数手册 `docs/PARAMETERS.md`。
- 尚未在 MMD 实机验收控制器，见 `docs/VALIDATION.md`。
