# mmecc

CicloO 的 MikuMikuEffect（MME）合集。适用于 MikuMikuDance 9.32 x64 + MME 0.37。

| MME | 简介 | 版本 |
|---|---|---|
| [AdvancedMotionBlur](AdvancedMotionBlur) | 动态模糊。支持镜头和模型动作、自动切镜处理及 PMX 表情控制 | 0.3.0 |

配布包发布后可从 [Releases](https://github.com/CicloO/mmecc/releases) 下载。解压后按包内的 `Readme.txt` 使用。
