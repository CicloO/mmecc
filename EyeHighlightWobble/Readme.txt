EyeHighlightWobble  ver.0.1.0
眼高光颤动（原 EyeHL_Distortion）
作者 CicloO

用于眼睛高光材质，让高光产生整体晃动和边缘形变。参数改由控制器 PMX 的表情调节，不再需要改 FX。

【文件】
EyeHLWobble_1.fx         标准：大幅慢速
EyeHLWobble_2.fx         细密：小幅快速
DrawEye_SJ_1.fx          标准 + 三金眼透的角度透明，用来代替 DrawEye.fx 给高光材质
DrawEye_SJ_2.fx          细密 + 三金角度透明
EyeHLWobble.fxsub        四个 FX 共用的控制与顶点着色器，需与 FX 放在同一目录
EyeHLWobbleCtrl.pmx      控制器（不可见模型），FX 按文件名绑定，请勿改名
Noise1.png / Noise2.png  噪波贴图，两种风格稍有不同

【使用】
1. 在 PE/材质页给眼睛高光材质分配其中一个 FX（高光材质顺序需在眼睛之下）。载入时如果报错，在 MME 控制版面勾选“工具-跳过设备验证”。
2. 载入 EyeHLWobbleCtrl.pmx，在 表情/其他 里调整。全部为 0 就是 FX 内的默认值。
3. 用三金眼透（_SJ 版）时，高光与 DrawEye 无需再保持两份参数一致：都读同一个控制器。
4. 多个角色共用一个控制器。需要分别控制时，复制 pmx 和 fx 并改名（FX 中 HL_CONTROLLER 改为新文件名）。

【表情】每对 + / - 为增减，+ 为 8 倍，- 为 1/8 倍，同时为 1 互相抵消。
[全] 停止      1 = 冻结所有颤动（回到原位）
[晃] 幅 / 速   整体晃动的幅度 / 速度
[震] 幅 / 速 / 密   边缘形变的幅度 / 速度 / 噪波密度
[防] 幅限      总位移上限；高光跑出眼睛范围时调小
[防] 前出      朝相机拉近的距离；被眼球遮住调大，浮到眼皮前调小
[防] 瞬        眨眼时抖动衰减；+ 增加（最多完全停止），- 减少（0 为不衰减）
[光] 亮        自发光亮度（默认 1.2）
[透] 消速 / 起点 / 透明   仅 _SJ 版：角度消失速度 / 消失起始点（±1）/ 基础透明度

【预设 VMD】Presets 文件夹，在载入控制器的状态下对控制器载入即可；每个 VMD 在第 0 帧写入全部表情（未用的写 0），切换预设会覆盖之前的值。
基于细密版（EyeHLWobble_2）的默认值：
EyeHLWobble_Subtle1.vmd   微弱：晃幅、晃速降低，震速不变，噪波密度略降
EyeHLWobble_Subtle2.vmd   微弱且更慢：同上，震速降为一半，噪波密度不变
效果受高光模型的顶点布线影响。
